# 支持与验收矩阵

目标平台只有 **Minecraft 1.20.1 / Forge 47.3.0 / Java 17**。下面区分实现、运行证据和仍需完成的验收，不能把编译通过当作兼容性结论。

| 领域 | 当前实现 | 证据与边界 |
| --- | --- | --- |

| 专用服务端 | 公共包与客户端入口已分离 | 仍需实际启动验收；不得自动接受 EULA |

## 原版域实施范围

以下是已批准路线的待实施领域，不是已完成声明：

- HUD、主菜单入口、暂停、生存/创造背包及真实容器贯通。
- 箱子、潜影盒、漏斗、发射器等储物容器，以及合成、熔炉族、酿造、铁砧、锻造、附魔、砂轮、切石、织布、制图、信标、交易等工作站。
- 聊天、书籍、告示牌、统计、进度及相关文字/信息界面；保留原有输入、服务器交互与确认语义。
- 标题、世界/服务器选择、选项及游戏前端；加载、连接、断开、死亡与转场。
- 明确的界面策略和恢复入口；未知类默认保留，不对所有 `Screen` 或所有纹理做无差别替换。

每个领域须按其真实入口和状态验证。仅打开一个白色样式面板、不使用原生容器控制器，或用本地物品数组代替服务器菜单，都不算该领域完成。

## 验收方法

1. 普通测试覆盖注册边界、状态转换、配置迁移等确定性契约。
2. 独立附属项目只以产出的发行 JAR 为依赖，检查其导入不越过公共 API。
3. 隔离客户端验证真实界面、输入、滚动、焦点、弹层、保存与世界生命周期，并保留截图和日志。
4. 专用服务端和至少两个独立客户端验证网络路径；集成世界不能替代这一步。
5. 发行 JAR 检查不包含开发预览、测试夹具或独立示例类。

公开 API 阶段的本机证据目录：`D:/saomenu-verify/framework-api-final`；运行日志位于同名前缀的 `-client/logs`。该阶段共 218 项普通测试通过；发行 JAR 含 54 个 API 类且不含开发预览或示例类。示例独立配置已保存 Unicode 标签和拖动坐标。Javadoc JAR 构建通过，但仍有公开成员注释完整性警告，未将其屏蔽。
