## 原版域实施范围

以下领域已分别完成真实原生界面验收；具体未覆盖边界仍按上表及下方证据说明保留，不推定全部 Minecraft/第三方屏幕兼容：

- HUD、主菜单入口、暂停、生存/创造背包及真实容器贯通。
- 箱子、潜影盒、漏斗、发射器等储物容器，以及合成、熔炉族、酿造、铁砧、锻造、附魔、砂轮、切石、织布、制图、信标、交易等工作站。
- 聊天、书籍、告示牌、统计、进度及相关文字/信息界面；保留原有输入、服务器交互与确认语义。
- 标题、世界/服务器选择、选项及游戏前端；加载、连接、断开、死亡与转场。
- 界面策略和恢复入口已实现；精确类匹配，未知类默认保留，不对所有 `Screen` 或所有纹理做无差别替换。

每个领域须按其真实入口和状态验证。仅打开一个白色样式面板、不使用原生容器控制器，或用本地物品数组代替服务器菜单，都不算该领域完成。

## 验收方法

1. 普通测试覆盖注册边界、状态转换、配置迁移等确定性契约。
2. 独立附属项目只以产出的发行 JAR 为依赖，检查其导入不越过公共 API。
3. 隔离客户端验证真实界面、输入、滚动、焦点、弹层、保存与世界生命周期，并保留截图和日志。
4. 专用服务端和至少两个独立客户端验证网络路径；集成世界不能替代这一步。
5. 发行 JAR 检查不包含开发预览、测试夹具或独立示例类。

公开 API 阶段的本机证据目录：`D:/saomenu-verify/framework-api-final`；运行日志位于同名前缀的 `-client/logs`。该阶段共 218 项普通测试通过；发行 JAR 含 54 个 API 类且不含开发预览或示例类。示例独立配置已保存 Unicode 标签和拖动坐标。Javadoc JAR 构建通过，但仍有公开成员注释完整性警告，未将其屏蔽。

恢复基础证据：`D:/saomenu-verify/recovery` 与 `D:/saomenu-verify/recovery-safe`；日志在对应 `-client/logs`。两次模式均正常退出；强制安全模式不能通过 F8、界面或 API 重启。原生背包中持有的八个苹果跨开关保持，并通过原生鼠标槽位操作移到目标槽，服务端确认。升级光环残留已修复：同一地面区域的青色粒子像素由修复前 8199 降到 0，不清空原版粒子引擎。该阶段发行 JAR 有 53 个 API 类（删除重复的包内绘图实现），不含开发/示例类，也不含原版默认字体覆盖；当时普通测试为 218 项全绿。

容器域证据：`D:/saomenu-verify/containers`，日志位于 `containers-client/logs`，出现 `containers native checks passed` 并正常退出。熔炉箭头的原生进度宽度保持不变，透明底材质去掉了旧灰色底块；目标背景像素由 `(198,198,198)` 变为当前表面色 `(234,235,236)`。创造搜索通过原生字符输入真正过滤为两种橡木木板，而不是只给 `EditBox.setValue` 后检查字段。未知背包子类仍呈现原生底板，F8 中途恢复不换容器实例。本轮不宣称配方幽灵自动放置、创造快捷栏保存/加载、信标次效果或操作系统输入法组合已经验证。
